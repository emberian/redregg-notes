Attempt:

  sum_spec equals closed form; GATE2 proves reassociation. Actual ML closures are

  File explicitly excludes changing trusted kernel/compiler code and says its

  compilerOpt/LAYERB.md documents actual altered CakeML bootstrap carrying a

  false. 'A verified live trusted-kernel/compiler replacement ran' also exceeds
  the inspected evidence. Preserve implementation identity in the certificate,
  outcome/effect/FFI traces in the translation theorem, and installation authority.

  and exact compiled artifact are bound to the same checked translation. Current

  Rich source lets an agent propose libraries/proofs without making compiler
  source or current proof checker mutable ambient authority. This realizes the
  interesting inhabitant loop more simply than copying Candle genealogy first.

Falsifier:
  A proposal carrying a true theorem about function A but installing function B
  must refuse even if chosen sample inputs agree. Replacing effectful function
  with same scalar answer but changed ordered effects must also refuse.

CARD 2 — Use the right prover pragmatically, but preserve the claimed statement

Human intent:
  May31 claude:5a0f6a2e-08ba-4cfc-aab1-f894f047703a #7519 asks for existing Iris,
  Rocq/Isabelle infrastructure and term transport for particular proofs, with

  context4: this follows a misleading 'only three problems remain' summary.

Attempt and source:
  docs/OPENTHEORY-LEAN-IMPORTER-PLAN.md and CV-COMPUTE-FEASIBILITY.md route foreign
  HOL results through an OpenTheory replayer. Current
  docs/opentheory-importer-poc/OTPoC.lean parses v6 commands and creates Lean Expr
  proof terms checked by addDecl. Its header records an actual correspondence
  failure: declared q|-p exported as the true p->p. Kernel acceptance certified
  ITS OWN statement, not equality to the declared foreign sequent. The repaired
  thm operation checks entire declared context and conclusion by content; axiom
  discharge is whitelist-to-proved-theorem, not creation of fresh Lean axioms.
  Missing bundled articles are hard errors. That directly addresses vacuous green.
  CV-COMPUTE report distinguishes ordinary reasoning import from compute logging:
  expanding cv_compute into primitive proof steps grows with reduction length.
  No fresh importer or HOL execution was performed here.
  Bread Resource.lean is a discrete resource algebra with frame-preserving
  updates. The source explicitly separates it from full step-indexed Iris OFE/
  camera/iProp machinery. 'Iris-inspired' is not a transported Iris proof corpus.

Lesson:
  Cross-system proof checking can be pragmatic without moving the whole project
  to a second prover. The encoding and statement correspondence are load-bearing.
  A source-language acceptance proof has the same limitation: any admitted Book
  is not necessarily the Book the user authored or the runtime actually executes.

Bend opportunity:
  Keep exact upstream Lean calculus as semantic boundary and make external proof
  evidence an optional source-indexed certificate. Check conclusion, all assumed
  definitions/imports, arithmetic/profile and context against publication bytes.
  No reason to import HOL4 or full Iris just to type Bool cases or world methods.
  Discrete resource algebra can help one-shot authority; it cannot turn Bend Q1
  affine use into physical noncopyability or current-law revocation by itself.

Falsifier:
  Change one imported assumption, one dependency identity, or one source type
  while preserving a true proof term: publication must refuse wrong correspondence.

  from one typed source, then connect a consumer. It does not mean repeated
  emitter wrappers or calling an arbitrary backend relation 'the spec'.

CARD 4 — Arbitrary CCC was an explicit target; finite tables are one answer

Human intent:
  July22 codex:019f87ab-aa9d-7ae1-a93b-a7b717103679 #108 demands either an
  arithmetization of arbitrary cartesian closed categories or a reason it cannot
  be done. Read cv around108/context5, including clarification that effectiveness
  and finite-model conditions cannot be hidden by retreating to finite types.

Actual source:
  FinitePolynomialFunctions / FinitePolynomialCCC use extensional finite tables,
  with exponential coordinate space. CCCPolynomialEvaluationFrontier proves
  variable function+argument evaluation has exact degree2 on valid one-hot codes;
  affine only when one side is subsingleton. Fixed function routing is linear.
  This does not enforce one-hotness or make function-space encoding succinct.
  CertifiedPresentationFibredCCC proves broad presentation-change category has
  no weak terminal object; fixed-source zero-resource evidence families are CCC.
  Logical conjunction is not product of equivalent presentations of one meaning.
  CertifiedIndexedPresentationCompiler keeps source-indexed fragments, exact
  acceptance certificates, explicit backend cost and conversion overhead, finite
  candidate search, and a free-glue counterexample. It explicitly requires actual
  adapters. Its historical four representation tags are not an execution-mode
  taxonomy for new Dregg.
  IntensionalCCCInteractionDescriptorIR2 binds full rule/path receipt and two
  receipt endpoint commitments. It explicitly proves forgetting source typed
  endpoints is irreversible: different beta redexes share layout. This is STLC
  local proof evidence, not general dependent affine Bend evaluation or the old
  HVM semantics. Receipt path uniqueness cannot restore erased source syntax.

Lesson:
  Preserve the useful distinctions: fixed/varying program, extensional/intensional,
  predicate/evidence, equality/simulation, semantic glue/materialized backend.
  The construction is not one blanket efficient compiler for arbitrary CCCs.

Bend opportunity:
  Rich language and static book closure allow partial evaluation of public code,
  immutable Data copying and explicit captures. Compile functions intensionally
  as closures/code/env, specializing known applications. Avoid one-hot coordinate
  per possible function. Reuse presentation contracts across supported carriers,
  but relation must include state/effects/errors/metering, not acceptance alone.

Falsifier:
  Two typed source terms with identical receipt layout but different runtime
  output must not share executable identity or substitute in a Bend statement.

  Nat.add/mul recurse over source data. Nat.sub saturates to0. Nat.divmod(_,0)
  returns (0,input). comp.ts:207-221 native arithmetic and349-358/448-453 bounded

  modulo2^48 source meaning; caller's final fault interpretation matters.
  Bread Bignum.lean gives signed ranged limb denotation and carry/borrow/modular
  relation witnesses; subtraction belowzero is UNSAT. Its header identifies two
  directions: DigitInjective gives limbs->value injectivity, but codec requires

  ofDigits/digitsN bounds and both inverse directions. RecordCircuit.range_iff

  generic truncation identity without term enumeration.
  FOLArithmetizationCounterexamples gives BabyBear cancellation and reversed
  zero-true connectives; Corrected gives nonnegative/no-wrap or Boolean graph
  repair. Not every semiring/ring supports residual AND=sum or OR=product.
