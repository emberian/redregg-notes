R5. Residency memory is technically durable but experientially stale.
Then: July25 allgame d41ad82c#806 asks longer scrolling context because lost
shared history and count limits make residency less enjoyable. #873 asks about
months being too distilled. Aug23 b42cbce2#920 wants moved/edited messages to
recraft context. Aug25 #1245 catches assistant inventing absent defaults.
Observed transcript: assistant plans backfill/foreverlogs/distillation and
reports repairs; its later classifier explanation is self-corrected. Those
reports are bounded captured claims; this pass ran nothing.
Current source: message dispatch really defaults to current room/topic. edits.py
patches pending edited content, logs edits, and explicitly records moves without
following across topic logs. Source is a useful boundary, not total live proof.
Hindsight: separate immutable event custody from current conversational/view
projection. Revision/move-aware references and context loading are product
semantics. Preserve history while making the present room match what people
meant and where the message now lives. Fine-grained event distinctions matter:
a preview re-render is not an authored edit; an edit is not a new statement;
a move need not authorize a second model reply.
Refuting scenario: queued reply answers an old version, reboot resurrects a
moved item, or one room's context silently becomes another room's history.
Implementation opportunity: feed edits/moves/source versions into one native
activity projection contract, while retaining platform-specific event adapters.
