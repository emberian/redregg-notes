
## The authoring text writes the interface a method produces (2026-10-27; LANG-103 critique (e); cv 01a17de6)

**What a program could not say.** LANG-103's `produces I` existed only in the core text, `(ℓ N I)` in the effects section: an author writing surface text could not declare the interface of the packages a generator installs, so the grade was unwritable in the authoring language and every such generator had to be built in Lean (`Std.generatorOf` plus a hand-set `effects` row, as GN22–GN24 do).

**What changed.** `Lang/Surface.lean`: a method's effect clause reads `(effect (moves N) [(produces I)])`; `I` is written as the surface writes a package's interface, a record of method and law names and types, `(rec (ℓ T)…)`, read by the surface's own type reader (`methodHead` now carries the `Ctx`), so named types, `Req`, `Verdict` and the rest resolve as in any surface type and a bad interface refuses by name at the offset (law 7). The lowering fills `Effect.produces`; install's `badProduces` and the run's `produces LABEL: lacks/type/extra M` are unchanged and now reachable from authoring. The grammar texts (`Surface.grammar`, `Read.grammar`'s effects entry, stale since LANG-103) and `docs/spec/2-structure.md` §2.7 state the form. GN25 is GN23's surface twin.

**MEASURED (hbox `~/nd-land/glm-f`).** `scripts/nd-build lake build Lang.Surface Lang.Proofs.Surface Lang.Resident lang-journey` green after one fix (a `Label × Ty` annotation on a `mapM` binder whose type Lean left metavariable); `lake exe lang-journey` GREEN, 1336 rows: GN25 `installed (admitted, 3240 bytes) and created (admitted); generate: refused "produces generate: lacks reset"; nothing born: true`, GN22–GN24 unchanged. The row's first draft was refused `idTaken`: its surface text (same doc as GN23's Lean-built package) lowered to byte-identical bytes, 3224, so the World already held the package — the lowering is exact, and the row's doc now differs.

**Premise price.** None: no theorem's statement changed, and the surface's produces rides the round-trip cases LANG-103 already proved for the core text (`effectSx_ok`, `effect_read`, `effects_mapM`), because the surface prints its package (`Print.package`) and reads it again with the one core reader.

**What re-emits.** Nothing: no shipped package's text changes, the core text and wire are untouched, and a grade without produces encodes exactly as before.

**Critique.** Both parts sit in the one `(effect …)` clause, moves first and produces second, matching the abstract grade (one `Effect` per method) and one duplicate check; a method that cannot move value still writes `(moves 0)` to reach its produces, the same asymmetry the core text's `(ℓ N I)` has, inherited rather than fixed. The interface is spelled as types the author must copy from somewhere (`Print.ty` of the promised package, as GN25 does, or by hand); the language has no name for "the interface of package P" in a type position — that is rung 2's checker-visible `quote` (DESIGN-META §10–11) — so this form is honestly a promise written out, not a derivation, and it is checked at generation, not at the generator's install. The declared interface carries no state type, so `createOf T`'s `T` is still untied to it (LANG-103's own open critique). Meta-critique: the pull was to parse the interface with the core reader's `ty depthMax` and skip the `Ctx`; the surface's own reader is what makes `Req`, `Verdict` and named types work in the clause, which is the surface's point, and threading `c` through `methodHead` cost six mechanical call sites.
