# The whole-file readers: collation (real 2026-10-24)

Nine Opus readers, one per layer, ~75,000 lines read whole of ~150,000; edits: none. Memos: READ-{KERNEL,LANG,LANGPROOFS,PROTOCOL,HOST,HOSTING,LEDGER-CENSUS-GATES,CODEC,RUST}.md. Below: every DEFECT, ranked by what the deployed system does wrong today; then the DEBT classes; then what was found SOUND. Each item names its memo and its measured/inferred status. The fix lanes are cut from this list, not from the memos.

## A. DEFECTS, ranked

A1 **A stale call gets a recorded, charged, final refusal under the wrong name.** (KERNEL, READ) `submit` runs `receive` on the Host's current cells BEFORE `World.admit` compares pins (Submit.lean:32–44; Call.lean:422); whichever law or receiver fails on the new state answers first (lawDenied / program / missingCell / noGrant), is authenticated, recorded, charged to the budget and made final. Defeats KERNEL-54; two code comments claim otherwise. Mutation: two writers race on an object whose law reads the old state: the loser is `lawDenied` forever, not `declined stale`. Fix: pin comparison before receive (the order of checks), + a row.

A2 **The declaration diff cannot see a change of meaning through a definition, and a declared RESTATES-MEANING is accepted on the declaration alone.** (GATES, MEASURED) `decls.py` digests statements by the NAMES of constants, not bodies: `∧ False` in a definition's body passed with 0 map lines; a theorem restated to `True` passed with one line. Under R-0069 this is the ONLY gate a fast landing runs (the census, certificate and plants run only at convergence). Fix: (i) the digest includes the bodies of defs the statement names one level down (the certificate's fourth pin, generalised); (ii) RESTATES-MEANING requires the new statement to be at least as strong OR a named second reader; (iii) the census + plants move into the fast path if they fit the budget (measure: the census ran in 1.3 s–12 s).

A3 **Frames are bounded per field, never as a whole: a follower one page behind cannot serve any command with argv > ~690 bytes.** (PROTOCOL, INFERRED from the arithmetic) A `resume` frame carries the continuation (whole argv) AND the page; a full page leaves < ~900 bytes. Covers every deployed `receipt CALL` confirm of an ordinary write and every real `install`. PROTOCOL-68 covered argv only; the rows page at 65,541 not 261,120 so cannot see it. FIRST: measure (compute the resume frame for a confirm continuation + a full-budget page; a row that puts the follower a full page behind and confirms). Then fix: bound the frame as a whole, or page the continuation out of the frame.

A4 **The escrow's joint judge never judges what a party receives.** (LANGPROOFS, READ) `offerJoint` reads only `role` and `terms`; θ affects nothing that moves; `escrow_fuse_admitted` holds for a fuse paying 5 α for 1 of anything. LANG-75.18 does not say this. Fix: the judge reads the legs (what each party gives and gets) and compliance relates them; theorem restated; LE row for the unfair deal refused.

A5 **`Proofs/Committed.journal_committed` (PROTOCOL-69) and `BellRow.answered_row_committed` bound nothing.** (HOSTING, READ) The last disjunct ranges over any call admitted at ANY World holding the bell: unbounded; the 10-20 vacuity under a new name. The first case of `answered_row_committed` is its own premise when `wb := wf`. Nothing deployed uses them. Fix: restate over follow's own path (an explicit list) or DELETE and say the join is at the text grain (HOSTING-44's honest form).

A6 **Open attempts are never looked up again.** (RUST, READ) CLIENT-25/27 and Attempt.lean promise "the next run looks it up"; only `reconcile` reloads an attempt (run.rs:195), only for an armed rotation. A re-run after `uncertain`/`open` signs a NEW call beside the frozen one: the double-effect window Attempt.lean warns of. The tests that "show" the next run do it by hand. Fix: every run begins by reloading the open attempt for the same argv (law 1: one place); a test that re-runs after `uncertain` and sees ONE call.

A7 **`nd cancel` exits ok on the Host's word alone.** (PROTOCOL, READ) `cancelAnswer` (Machine.lean:1136–1146): the same trust class T0 closed at step 4; no row has a Host lying about a cancel. Fix: cancel settles on follow's own World like step 4; a lying-cancel row.

A8 **An honest shutdown is reported as the Host lying.** (HOST, READ) At exit the writer answers queued frames `refused stopped` (final status) though its docstring says resend is safe; the client confirms with follow, follow says open → `contradicted (hostContradicted refused open)`. Lookup of undecodable bytes answers `refused` where submit answers `declined`. Fix: `declined stopped` (retryable), consistent `declined` for undecodable; a row.

A9 **The writer's refinement theorem is about a follower nobody runs.** (HOST, READ) `host_run_audits`/`host_run_kept` are over `Kernel.Receive.audit`; the deployed follower runs `Protocol.Command.absorbStep` (a second re-deriver: law 1), which differs (refusal record compare; recorded stale). For the bytes the follower reads, an honest page is proved accepted only for cancels. Fix: ONE re-deriver (absorbStep defined as audit over decoded bytes, or audit deleted), the refinement restated over it.

A10 **A plain package cannot import an installed contextual package.** (LANG, MEASURED) Install picks its import loader from whether the ROOT has holes; a run picks per package; install refuses what the run loads (`illTyped noHole @execute…`, blaming the import). LANG-35 says install loads imports exactly as a run does. Fix: one loader (law 1), chosen per package at install as at run; a journey row that layers a plain package over the Bell.

A11 **The hole's coverage check reports a missing pin under a real verdict's name.** (LANG, MEASURED) An omitted support pin and a withdrawn fact both refuse `support0 withdrawn`; an omitted blocker pin refuses `pruned`; deleting the coverage check changes no `select` output (law 7). A12 **Std.offer / Std.offerEscrow session rows can never be removed: ≤ 1024 deals per object, ever.** (LANG, READ) LANG-76 fixed this for activities and left these byte-identical on purpose. Fix: a patience + retire on the session row, as the activity got.

A13 **A refusal class the resident retries every second forever.** (HOSTING, READ) Invoke replies with exit declined/uncertain/behind/client/open/hostContradicted/pageIo never reach the re-read branch; retried without limit; never exits by name (Run.lean:367), breaking its own rule at :137–139; `deliverAfter_unsettled`'s docstring calls these crash-stop. A16 **The miscompile gate catches one spelling.** (CODEC, MEASURED) `gates/refusals.py` catches `\xHH`+hexdigit only; its own workaround `"\x00" ++ "b"` folds to the same broken C literal; `"a\u0000b"` slips past; compiled `[11,0]` vs interpreter `[0,98]`. A17 **Law 2 does not hold as written: hand-written Rust knows byte layouts.** (CODEC + RUST, READ) frame.rs/mux.rs (one length `unwrap_or(u32::MAX)`), the 72-byte custody record, `HEADER = 4`/`CONN = 4`, emitter templates checked only by 19 path_clean vectors; receipt line prefixes, socket names, the 4-byte conn id ×3, restart constants. A20 **The stdio-leg tcb row is four trusts, not one sentence about bytes.** (HOSTING + GATES, READ) It bundles: one follower serves the resident; follow's World moves only by the frames it answers; a restarted follow reopens what it persisted; which continuation nd sends back.
