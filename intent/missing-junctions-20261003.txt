FIVE ACTIONABLE HYPOTHESES FOR NEW DREGG — PROPOSED, NOT RECOVERED ORDERS

H1 Portable evidence envelope (Q1/Q3): one typed object binds subject/issuer/source
identity, grant instance, accepted state/version/root, clock domain/freshness and
revocation proof or status. An independent local viewer can carry it through a chat
or file without needing whole history; a receiver checks current action authority
separately. First falsifier: revoke/regrant a reused slot, replay old evidence after
an epoch change, and try substituting a different key for the same cell. Consumer:
sharing a tool/document between two sovereign local worlds and a rented provider.
October13 relevance: exact native authority/evidence and the chosen agreement join.
Broader human-channel/offline portability is a suggested later tranche.

H2 Versioned live-change contract (Q2/Q3/Q8): Bend module/method identity plus a
bounded migration plan binds old/new state, outstanding calls/returns/reservations,
resource accounting, accepted authority and provider lifecycle. Reuse actual Orb
reload/drain laws as vocabulary; do not claim physical FD migration from them.
First falsifier: update a method/policy while an old accepted call owes a private
return; it must finish under its admitted contract or an explicit authorized
handoff, never silently reinterpret or disappear. Consumer: room-authored tools,
member OO and a hosted service surviving deployment/restart. Coherent current
receiving/recovery matters by October13; richer hot upgrades are later suggestions.

H3 Funded creation as an ordinary atomic authored operation (Q2/Q5/Q6): generated
factory descriptors install exact source/program/policy identity, capability
endowment and budget/resource flow in one accepted old-image batch. Internal value
sequencing must not let freshly minted authority sign its own birth. First falsifier:
try a descriptor substitution and a same-batch unauthorized grant; an ordinary
funded new tool must still succeed. Consumer: creating a hosted room tool or game
object, then invoking it from Starbridge. Mini already supplies one-old-image birth
nuclei; investigate its actual receiver before inventing another kernel. An atomic
flash-loan factory or foreign NFT export is a later discriminating experiment.

H4 Portable presentation with exact trusted actuation (Q4/Q6): derive views and
invocation schemas from authored native kinds/methods, but keep the trusted identity/
consent context explicit for every host. First falsifier: embedded page changes the
object/argument/origin shown after consent or overlays a fake 'verified' affordance;
it must not produce an approved native intent for another action. Consumer: same
document/poll/tool in Starbridge and an existing social/web surface. October13
scope is meaningful native docuverse/deos actuation; arbitrary hostile embedding
and browser extensions are proposed October26/November work, not recovered gates.

H5 Context lineage and bounded resident work (Q7/Q1/Q6): retained events, edit/move/
redaction records, summary dependencies, loaded context version and tool-work
subcontext are explicit. Small delegated tool jobs return provenance-bound results
to the informed main session; provider failover preserves operation identity and
does not bill/dispatch twice. First falsifiers: summarized private fact survives
authorized redaction, backfill resurrects a tombstoned event, changed system prefix
invalidates every cache, or failover loses/duplicates the pending reply. Consumer:
resident Hermes that remains informed and useful after a disconnect/restart.
October13 scope is mature resident request/reply/recovery. Derived-memory rewrite,
autonomous multi-provider optimization and comprehensive forgetting semantics are
later suggestions; stored bytes/third-party provider custody cannot be wished away.
