REDREGG — a research and design home for Dregg's past and possible futures

Created October 3, 2026, at Ember's request. Local-only: no remote or publication.
This directory holds historical intent reconstruction, source archaeology,
lessons from attempts, and proposed coherent designs. Mini remains the current
construction home. This is not a decision to rewrite or move either repository.

START HERE
catalog/imports.json — immutable first-pass report snapshots and source hashes.
archive/2026-10-03/ — initial research, synthesis and coverage reports.
work/PLAN.txt — active second-pass owners, questions and expected outputs.

STRUCTURE
intent/     Human intentions, corrections, tensions, chronology; source locators.
landscape/  Actual products/subsystems and their relationships, not only layers.
replays/    Intent -> attempted design -> observed outcome -> hindsight proposal.
designs/    Alternatives, coherent user experiences, tradeoffs and falsifiers.
catalog/    Evidence/claim indexes, source provenance and cross-links.
coverage/   What was extracted, actually read, deduplicated, or still missing.
archive/    Dated snapshots. New evidence changes current synthesis, not old files.
work/       Ownership and progress; current implementation stays in Mini trackers.

READING RULES
Separate human-authored request, hope, exploratory idea, quoted paste, agent
proposal, implementation claim, captured evidence and new inference. A user-role
transcript row may be an automated notification or delegated brief. Do not count
forks/compaction repeats as independent endorsement. Reading an agent summary is
not reading its sources. Preserve counterexamples, changes of mind and unresolved
tensions; do not invent a psychological profile or reduce intent to one slogan.

A useful claim has exact cv session/message/date or file/revision/artifact,
status (read/inferred/proposed), scope, later corrections and consumers. Source
proof, compilation, native receiving and deployed use are different evidence.
October 13 requirements and suggested October 26/November work remain distinct.

RAW MATERIAL AND PRIVACY
Raw prompt corpora stay at their original private workbox paths, indexed rather
than blindly imported. Never copy credentials, API keys, private provider state,
or full personal transcript dumps into this repository. Keep raw/private dirs
untracked. Local Git preserves curated research; no remote push/publication is
implied. Source snapshots are agent reports, not substitute primary evidence.

CONSTRUCTION PRINCIPLE
Use research to make Mini more capable and coherent. Do not turn this archive
into a substitute for completing and integrating the running system. Reuse,
adaptation, specification mining and independent re-design are distinct choices.
